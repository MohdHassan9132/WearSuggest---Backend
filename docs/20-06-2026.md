# Git Workflow - WearSuggest Backend

## Quick Cheat Sheet

### See Current Branch

git branch

The branch with * is the current branch.

---

### Check Current Status

git status

Expected before switching branches:

nothing to commit, working tree clean

---

### Switch Branches

Switch to main:

git checkout main

Switch to refactor branch:

git checkout seller-controller-service-repository-refactor

Switch to try-on feature branch:

git checkout try-on-feature

---

### Create New Feature Branch

Always create from main:

git checkout main

git checkout -b feature-name

Example:

git checkout -b clothing-feature

---

### Push New Branch To GitHub

git push -u origin branch-name

Example:

git push -u origin clothing-feature

---

### Save Progress

git add .

git commit -m "message"

git push

---

### See Recent Commits

git log --oneline -10

---

### Visualize Branches

git log --oneline --decorate --graph --all -10

---

### Verify Tracking Branches

git branch -vv

---

### Delete Local Branch After Merge

git branch -d branch-name

Example:

git branch -d try-on-feature

---

### Delete Remote Branch After Merge

git push origin --delete branch-name

Example:

git push origin --delete try-on-feature

---
